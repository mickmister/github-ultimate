# Pi Web demo

This is the agegr Pi Web interface running as a static GitHub Ultimate branch preview.

## Quick Start

Choose a tutorial conversation in the sidebar, inspect its tool calls and files, or send a message to see a simulated streaming reply.

The demo runs in your browser with sample data. Replies are pre-written; no model, server, shell or credentials are used. Edits and new conversations are temporary and reset when the page reloads.

## Files

The file explorer contains an explicit public fixture list from the vendored Pi Web source. It does not expose the enclosing GitHub Ultimate repository or your workspace files.
