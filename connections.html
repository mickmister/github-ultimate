Without replacement, uploads use If-None-Match: *. A service that cannot enforce that condition returns an error; no overwrite fallback is attempted. Objects are limited to 8 MiB per read/upload.

Disconnect removes local credentials only. To revoke the GitHub authorization, visit GitHub authorized Apps. Multiple local connections to the same App can share its upstream authorization; revoking it can affect all of them.

Page data storage

Approve page-data reads/writes independently of GitHub/S3 connections. Data is shared by exact origin (scheme, host, port); approved subpaths control access, not separate data namespaces. Do not store credentials here. Revoking access retains data; clear it from an approved page when needed.

Workspace cache

Device-local limits apply to persisted reads. Documents and Dolt have separate workspace counts and share the total capacity. Old workspace data is evicted first; authoritative remote data and authored drafts are retained.
